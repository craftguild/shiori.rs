# Third-party notices

First-party shiori.rs source is licensed under MIT OR Apache-2.0. Cargo.lock records registry versions/checksums and complete public Git revisions for Chigiri, Oriha and Standards common crates. `cargo deny check advisories bans licenses sources` checks the resolved Rust graph; `shiori sbom` reports the actual distribution graph and supplemental embedded components.

## Embedded GraphiQL

Chigiri's optional GraphiQL assets are embedded in the executable, including JavaScript/CSS workers, the Monaco codicon font and original notices. When enabled, `/graphiql/assets/THIRD_PARTY_NOTICES.txt` serves their rights notices. The distribution build verifies the pinned upstream asset inventory, exact bytes and esbuild-derived package inclusion/license record, then includes only the packages marked as bundled in the SBOM. The [upstream inventory](https://github.com/craftguild/chigiri.rs/blob/5f90235ddb705a1a394b9a5cfda23a9ea62dc4b6/crates/graphiql/asset-inventory.json) remains the authority. Node.js, esbuild and unused npm packages are not runtime dependencies merely because they produced those assets.

## Renderer resources and data

Oriha embeds unmodified STIX Two Math v2.13 b171 under SIL OFL 1.1 and may return it as a base64 font resource. Preserve the [STIX license](notices/STIX-OFL.txt), reserved font names and original attribution when redistributing font copies. Its [upstream provenance](https://github.com/craftguild/oriha.rs/blob/d46fa615fcd0e5d5ad730342436188ddb5a0e917/crates/latex/assets/fonts/README.md) records the source and SHA-256. Compiled WHATWG character references, GitHub gemoji aliases and Unicode-derived emoji data retain the upstream BSD-3-Clause, MIT and Unicode-3.0 terms. Their pinned source records and the actual compiled tables are represented by the build's supplemental SBOM evidence.

## Native image encoder

The locked libwebp-sys 0.9.6 package statically compiles bundled libwebp 1.3.1 and sharpyuv. Retain its [copyright/license](notices/libwebp-COPYING.txt) and [patent grant](notices/libwebp-PATENTS.txt). Image decoding uses the locked Rust image codecs; no system WebP or codec download is needed at runtime.

## Banner and fixtures

The committed ASCII banner is generated by the pinned Standards engine from Glenn Chappell's Small Slant font with Paul Burton's 1996 layout update. Retain the [FIGlet BSD license](notices/FIGlet-LICENSE); the font renderer is a build tool rather than a runtime dependency. ICC test fixtures are from Compact ICC Profiles revision `bdd84663061bc4ae95ca70decff54f581e27f702` under CC0-1.0. See their [exact provenance](../crates/shiori/tests/fixtures/icc-provenance.json) and [original license](../crates/shiori/tests/fixtures/compact-icc-license.txt). Test-only fixtures do not enter the executable's runtime SBOM.
